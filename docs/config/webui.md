# WebUI 控制台指南

PicoOnebot 内置了一套现代化的 Web 管理控制台，用于查看机器人实时状态、扫码登录、管理网络连接与密钥鉴权。

---

## 访问与认证

- **访问地址**：`http://<运行设备或服务器IP>:6099`
- **初始默认密码**：`picopico`

首次使用该密码登录后，系统将弹出强制修改密码对话框，设置新密码后请妥善保管。若后续需要再次修改密码，可在控制台右上角「系统设置」中进行调整。

---

## 控制台核心面板

### 1. 仪表盘与登录管理 (Dashboard)
- **实时连接状态**：显示当前 QQ 账号是否已成功与腾讯服务器建立在线会话；
- **扫码登录区域**：
  - 未登录时动态刷新二维码；
  - 使用手机 QQ 客户端扫码后，状态将自动变更为「登录成功」并拉取当前机器人的昵称、头像与 UIN；
- **登出与重新扫码**：支持在界面上一键注销当前账号并重新生成二维码切换登录账号。

### 2. 网络配置面板 (Network Settings)
用于管理 OneBot v11 协议的上报通道。支持实时新增、开启/禁用或删除配置项，修改无需重启容器，保存后即刻热重载生效：
- **反向 WebSocket 配置**：指定下游框架的服务端地址、重连间隔及 Access Token；
- **正向 WebSocket 服务**：控制本地正向 WebSocket 服务监听端口与连接鉴权；
- **HTTP 上报与 API**：配置 HTTP 消息事件 POST 接收端地址与 HTTP API 调用监听端。

### 3. 日志监控面板 (Live Logs)
- 实时抓取并滚动展示应用核心 Hook 层与 OneBot 协议层的关键事件日志；
- 支持按日志级别（`INFO` / `WARN` / `ERROR`）筛选过滤；
- 便于快速定位消息是否成功解析、是否顺利推送至机器人框架。
